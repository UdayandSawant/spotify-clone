# Spotify Clone

A responsive Spotify-inspired music streaming web application built using HTML, CSS, and JavaScript.

## Features
- Music player UI
- Responsive design
- Play/Pause controls
- Playlist section
- Interactive interface

## Tech Stack
- HTML5
- CSS3
- JavaScript
